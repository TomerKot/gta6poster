# Безпека: модель загроз і що зроблено

## Що захищаємо
1. **Токен бота** — з ним можуть постити в канал від твого імені.
2. **Акаунт GitHub / репозиторій** — з ним можуть підмінити код бота.
3. **Репутацію каналу** — спам, скам-посилання, malware, бан від Telegram.

## Загрози та контрзаходи

| Загроза | Захід |
|---|---|
| Витік токена в git | Токен лише в GitHub Secrets; `.gitignore` для `.env`; Secret scanning + Push protection |
| Витік токена в логах | `telegram.py` логує лише тип помилки (виняток `requests` містить URL із токеном); GitHub маскує секрети в логах |
| Зламаний/викрадений токен | `@BotFather → /revoke`; бот має лише право «Публікація повідомлень», не може керувати каналом |
| Шкідливі посилання (фішинг, «GTA 6 APK/beta/free download») | Блок-лист у `config.toml`; публікуємо тільки http(s) URL, прибираємо трекінг; джерела — лише whitelist із конфігу |
| Ін'єкція розмітки / XSS у Telegram | Увесь зовнішній текст проходить `html.escape`; HTML у фідах вирізається до тексту |
| Шкідливий/гігантський фід (XML-бомба, memory DoS) | Ліміт 2 МБ, таймаути 5/15 с, тільки `https://`, парсер `feedparser`, помилка одного джерела не валить решту |
| Компрометація залежностей (supply chain) | Лише 2 залежності з піном версій; Dependabot щотижня; `tomllib`/`html.parser` зі стандартної бібліотеки |
| Компрометація GitHub Actions | Мінімальні `permissions`; немає тригерів `pull_request` для робочого workflow (форки не бачать секретів); радимо запінити дії на commit SHA |
| Захоплення акаунта GitHub | Вмикни **2FA (passkey / TOTP)**, не використовуй той самий пароль |
| Спам-флуд у канал | `max_posts_per_run`, пауза між постами, дедуп, перший запуск без публікацій |
| Prompt injection | LLM у проєкті **не використовується**. Якщо додаватимеш ШІ-резюме — вхідний текст вважати недовіреним, не давати моделі жодних інструментів |

## Юридичне/платформне
- Не копіюємо статті цілком: заголовок + короткий уривок + лінк + назва джерела.
- Блокуємо «витоки» відео/збірок/ассетів (Rockstar/Take-Two активно подають DMCA).
- Не скрапимо X/Reddit в обхід ToS.
- Для каналу вкажи в описі, що це неофіційний фан-канал, не пов'язаний з Rockstar/Take-Two.

## Якщо щось пішло не так
1. `/revoke` токена в BotFather → новий токен у Secrets.
2. Settings → Actions → Disable, перегляди історію комітів і логи запусків.
3. Змінити пароль GitHub, перевірити активні сесії й SSH/PAT-токени.
